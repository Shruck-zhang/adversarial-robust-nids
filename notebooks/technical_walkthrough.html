Adversarial-Robust NIDS — technical walkthrough¶

A reproducible tour of a two-layer deep-learning intrusion detection system: a broad model comparison, an adversarial-robustness study, the resulting two-tier detector, a real-time streaming design, and automated validation. Every table and figure below is regenerated from the committed results in results/.

At a glance

  • 11 model families compared on the corrected CICIDS2017 with imbalance-aware metrics
  • FGSM/PGD attacks + adversarial training across architectures
  • A two-tier XGBoost + hardened-DNN core behind a signature rule layer (defence in depth)
  • Real-time CICFlowMeter pipeline; a 5-layer automated test suite (43/43)

1 Problem & data¶

Flow-based intrusion detection on the corrected CICIDS2017 (Engelen et al., WTMC 2021), which fixes flow-construction and labelling defects in the original release. 1.84 M deduplicated flows → an 8-class taxonomy, a leakage-free group split (train 1.10 M / val 367 k / test 367 k), and 66 pruned features. Because the data is 78 % benign, everything is reported with macro-F1, balanced accuracy, MCC and per-class FPR — never headline accuracy.

Gradient-boosted trees lead on tabular flow data (XGBoost 0.967, lowest false alarm); the DNN is the best differentiable model; recurrent models are worst — per-flow features carry no temporal ordering, so LSTM/GRU have nothing to exploit (a useful negative control). No single architecture wins on every axis — which motivates the two-tier design in §4.

4 Two-tier defence in depth¶

Pairing a non-differentiable tree (XGBoost, best clean) with an adversarially-hardened DNN, fused so an attacker must fool both.

Perturbations crafted on the DNN transfer to XGBoost (evasion up to 0.67) — a tree is not inherently safe. The hardened DNN resists (~0.02), so the two-tier system stays robust while keeping macro-F1 ≈ 0.96 and ~0.5 % false alarms.

5 Real-time detection engine¶

A signature rule layer (fast, explainable) runs before the two-tier AI. Live traffic is turned into flows by CICFlowMeter's live monitor — the same extractor as training, so no feature skew — and scored the instant each flow completes.

A 5-layer harness (unit → integration → performance → robustness → attack-simulation) with per-metric acceptance thresholds; 43/43 pass, batch throughput ~159k flows/s. The suite also caught and fixed a real malformed-input robustness bug.

7 Positioning¶

The design follows two threads in the literature: evidence that tree models rival deep nets on tabular data, and the adversarial fragility of deep NIDS. The contribution here is to combine a broad, imbalance-aware comparison with adversarial hardening and to package the result as a real-time, defence-in-depth system that is honestly stress-tested rather than only benchmarked on clean data.
